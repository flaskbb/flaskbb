# Паспорт проекта FlaskBB

## 1. Общая информация

**Название проекта:** FlaskBB.

**Тип проекта:** веб-приложение — форум.

**Происхождение:** форк существующего проекта с открытым исходным кодом GitHub.

**Оригинальный репозиторий:** https://github.com/flaskbb/flaskbb

**Репозиторий команды:** https://github.com/sinveria/flaskbb

**Исходный коммит:** 1028f176.

**Лицензия:** BSD 3-Clause.

## 2. Назначение проекта

FlaskBB — веб-приложение для создания и управления
интернет-форумами и тематическими сообществами.

Проект предназначен для организации общения пользователей,
обмена информацией и обсуждения различных тем.

Система предоставляет инструменты для управления
пользователями, публикациями, форумами и правами доступа.

В рамках лабораторных работ команда будет изучать существующий
проект, анализировать его архитектуру и выполнять
согласованные изменения серверной и клиентской частей.

## 3. Целевые пользователи и роли

В проекте предусмотрены следующие категории пользователей:

- Гость — просмотр доступных разделов форума.
- Зарегистрированный пользователь — создание тем,
  публикация сообщений и управление профилем.
- Модератор — контроль содержимого форума и соблюдения правил.
- Администратор — управление настройками системы,
  пользователями и структурой форума.

## 4. Основные сущности предметной области

1. Пользователь (User) — участник форума.
2. Группа (Group) — объединение пользователей с определёнными
   правами доступа.
3. Форум (Forum) — тематический раздел для обсуждений.
4. Тема (Topic) — отдельное обсуждение внутри форума.
5. Сообщение (Post) — публикация пользователя в теме.

## 5. Основные пользовательские функции

1. Регистрация и авторизация пользователей.
2. Просмотр форумов и тематических разделов.
3. Создание новых тем обсуждения.
4. Публикация сообщений.
5. Редактирование и удаление сообщений.
6. Управление пользовательским профилем.
7. Поиск по содержимому форума.
8. Управление пользователями и правами доступа.

## 6. Технологический стек

- Язык программирования: Python.
- Минимальная версия Python: 3.12.
- Серверная платформа: Flask.
- Шаблонизация: Jinja2.
- Система управления зависимостями: uv.
- Файл фиксации зависимостей: uv.lock.
- Клиентская часть: HTML, CSS, JavaScript.
- Система тестирования: pytest.
- Система контроля версий: Git.
- Платформа размещения репозитория: GitHub.
